# Custom code for De Jong et al. (2025)
---
This repository contains custom code used to analyze patterns of seasonal influenza virus circulation in the United States:

> Simon P.J. de Jong, Andrew J.K. Conlan, Alvin X. Han, Colin A. Russell (2025). Mobility-driven competition between transmission lineages shapes seasonal influenza epidemics in the United States.

---

Analysis scripts can be found in the **scripts** folder. Code used to generate figures can be found in the **figures** folder.
